# AGENTS.md

## Convenções de trabalho

- Sempre commitar e fazer push das mudanças ao terminar uma tarefa (padrão do usuário: "commit + push, sempre").
- Mensagens de commit em português, estilo `feat:` / `fix:` descritivo (ex.: `feat: marcar lancamento existente como recorrente...`).
- Commitar apenas arquivos relacionados à tarefa atual; mudanças de outras sessões ficam para serem committadas separadamente.
